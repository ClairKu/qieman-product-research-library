一、统一设计原则

推品优先有效曝光→匹配→签约，不为堆功能
定制 > 标准有定制条件先推定制/场景方案
主次清晰主动匹配 > 风险发现 > 工具专区 > DIY
组件生产运营可编排；用户可裁剪（后置）

信息架构主次

首屏：为我匹配→ 风险/目标发现→ 四笔钱主推货架→ 工具与专区→ 严选/DIY
User → 轻量意图/KYC（可跳过但降级）
→ MatchEngine（定制账户 / 场景方案 / 矩阵策略）
→ PageComposer（官方组件编排 · 客群模板）
→ 组件：定制卡 · 风险地图 · 四笔钱货架 · 规划入口 · 温度计 · 专区 · 严选
→ 交易 / 陪伴回流 → 再匹配

二、三套方案一览

方案 A · 服务货架升级
最快上线

传统一级页增强：收束工具入口，按矩阵重排四笔钱/严选，定制入口强化。

  • 改动面小，承接换品
  • 仍偏「货架心智」
  • 可视化与千人千面弱
方案 B · 风险地图发现
选品体验

晨星风险分 × 收益/回撤二维视图 + 滑杆，与列表联动。

  • 解决「只会点头部」
  • 需矩阵数据治理
  • alone 仍缺服务编排
方案 C · AI 组件化服务页
主航道

页面=可编排服务组件；运营调模板；用户可增减可选模块。

  • 改变生产方式
  • 对接小顾/实验室
  • 工程与治理成本更高

六、路径主次取舍（落地口径）

路径主次投顾页动作不做
主动推品主首屏匹配结果 + 主推高亮无差别轮播堆品
定制方案主有条件强制优先于列表把定制藏在 Banner tip
规划（四笔钱/养老/攒钱）主辅助组件入口；结果回流匹配多个规划 Banner 并列抢首屏

DIY次严选/估值/自建沉底占首屏

七、与矩阵 / 合规 / 小顾的衔接

策略矩阵

  • 以矩阵冻结「主推集合」，现网独有品（货币三佳、超级理财加、保险）进「运营扩展位」或补入矩阵。
  • 新品（稳健3070、守恒、行业风向标）有策略页+陪伴包才上风险地图。
  • 私募占位不进零售默认模板。

合规与小顾

  • P1 起：轻量意图/KYC 后再展示完整地图（可浏览降级列表）。
  • 匹配话术与适当性留痕复用投顾 2.0。
  • 小顾可唤起同一组件（C-MATCH / C-RISKMAP），避免两套货架。

附录 · 方案 A/B/C 单独说明

A. 服务货架升级

保留现结构，做减法与换品：定制卡视觉升权；四笔钱按矩阵梯度排序；底部工具收成「工具抽屉」；严选保留。适合矩阵紧急上新，但不解决产品库心智。

B. 风险地图发现

以可视化替代纯列表。建议「风险轨道 + 散点」双模：轨道适合拇指滑动，散点适合桌面/深度比较。指标切换要有合规脚注（历史业绩不预示未来）。

C. AI 组件化服务页

把投顾页定义为「服务编排画布」。官方模板：新客转化版 / 老客调优版 / 市场敏感版 / 小白兜底版。运营改的是组件参数与顺序，而不是每次重做页面。这是 AI 产品工厂在 C 端一级页的样板间。
