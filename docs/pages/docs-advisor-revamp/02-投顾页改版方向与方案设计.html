投顾页改版方向与方案设计

在品类矩阵与推品逻辑升级背景下，把投顾一级页从「策略货架」升级为「推品中枢」。核心原则：优先推定制方案，再推标准策略；同时实践 AI 产品工厂——官方组件可编排、运营可调、用户可选布局。

对齐结论（建议先拍板）

  • 推荐主路径：方案 C（AI 编排服务页）为骨架 + 方案 D（风险地图）为货架增强 + 方案 B 的定制优先漏斗。
  • 方案 A（传统货架增强）只作过渡/兜底，不作为终局。
  • 下一阶段产出：选定主方案后做高保真 DEMO + 产品规划计划书。
原则 主次取舍 AI 工厂 可视化 四套方案 对比 对齐投票

1. 改版原则

P1 · 推品是唯一北极星

一切模块取舍以「是否提高合适方案的曝光→理解→采纳→交易」为准。

P2 · 定制优先，标准兜底

能定制则定制；活钱/稳钱可标准策略直推；长钱/复杂目标优先定制。

P3 · 工具服务货架，货架不淹没工具

温度计/估值/风险地图服务于找品与解释，不与主推抢首屏。

P4 · AI 工厂生产方式

页面=组件编排；官方默认布局 + 运营实验位 + 用户可选模块。

2. 能力主次取舍

层级能力一级页职责取舍
L0 首屏 为我推荐（定制/主推）、目标快捷入口、服务状态摘要 完成「下一笔钱该怎么配」 必做
L1 主路径 四笔钱导航、定制方案、标准策略货架、持仓调优入口 按目标/场景完成推品 必做
L2 增强 风险—收益地图、严选层、养老/全球/攒钱专区摘要 提高理解与发现效率 本期强烈建议
L3 可选 每日估值、温度计精简卡、自建/DIY、用户自定义布局 服务专业用户与留存 组件化，默认折叠/可选
L4 不做进主叙事 私享理财全流程、额度/支付基建、长内容流 分别归属资产/交易/发现 仅保留跳转，不堆模块
识别意图 轻量目标/KYC 可定制？ 定制方案 否则四笔钱/严选 交易+陪伴

并行旁路：持仓调优 · 风险地图浏览 · DIY/估值找品

生产方式（AI 产品工厂落地）

  1. 组件定义：输入（用户画像/持仓/品类）、输出（卡片 UI + 跳转 + 埋点）、评测集。
  2. 编排发布：AI 实验室/运营台选择模板 → 预览 → 灰度 → 全量。
  3. 千人千面规则：新户偏规划+主推；在管户偏调优+加仓；高阶户偏地图+严选+DIY。
  4. 治理：组件有 owner、版本、成功率、推品贡献；60 天无效则归档。
