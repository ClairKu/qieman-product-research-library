90-DAY ACTION PLAN

先把漏斗测准，再缩短路径

建议把工作拆成观测、体验、增长三条线；前两条优先级更高。

P0 · 1—2 周

统一指标与身份

  • 补齐登录、开通、Key、配置、首调成功事件
  • 打通神策用户、登录用户与 OAP 用户 ID
  • 给未命名输入框和按钮补业务名称
P0 · 1—2 周

合并入口与路径

  • 选定 /mcp 为唯一 canonical
  • 旧首页 301/308 到唯一地址
  • 修正 service-ativation 并保留历史映射
P1 · 3—6 周

缩短开通与配置

  • 登录后返回原目标，不回落首页
  • 开通成功直接给 Key、配置与测试调用
  • 补进度、成功状态、错误解释与重试
P2 · 6—12 周

放大有效渠道

  • 建设基金数据 MCP / Skills SEO 专题页
  • 为微信、飞书、百炼等入口设置渠道参数
  • 按渠道看开通、首调和 7 日留存
