一、且慢APP「投顾」一级页面的当前结构与内容模块

重要说明：且慢官网（qieman.com）为前端动态渲染（SPA），无法直接抓取页面内容；APP 一级页面的精确布局截图未能通过公开渠道获取。以下结构基于 App Store 官方应用描述（2026年更新版）、官网 URL 路径、第三方应用情报页与用户评价交叉还原，可信度较高但非逐像素验证。

1.1 核心信息架构（据 App Store 官方描述，2026年）

且慢当前版本（iOS 4.8.109，安卓/鸿蒙 4.8.106+）的产品主线为「四笔钱资产配置 + 严选策略 + 定制方案 + AI小顾」：

  • 四笔钱：APP 首页核心框架，将资金按用途分为四个账户入口：
  • 活钱管理——日常随时要用的钱，货币基金承接（代表策略「货币三佳」）；
  • 稳健理财（稳钱）——半年至三年内有明确用途的钱，债基/固收+策略承接（代表策略「我要稳稳的幸福」「南方梦想佳」「马拉松固收增强」）；
  • 长期投资（长钱）——3~5年不用的钱，权益类策略承接（代表策略「长赢指数投资计划」「春华秋实」，官网路径 qieman.com/m4/M4_LONGTERM 即长钱板块）；
  • 保险保障——风险托底，由且慢精选合作伙伴提供保险产品。
  • 官网四笔钱入口路径为 qieman.com/m4。
  • 严选策略：官方描述为「帮您过滤噪音，仅展示严格筛选过的优质投资策略，并按风险等级划分投资周期（活钱、稳钱、长钱），方便用户自动匹配适合的策略」。首页只展示精选策略而非爆款产品、不做排行榜，是且慢区别于基金超市类平台的核心设计。
  • 定制方案服务：官方描述为「投前基于用户财务现状与目标，定制专属投资计划书；投中结合市场行情变化，动态调整组合配比；投后全程跟踪陪伴」。
  • AI小顾：24小时 AI 投顾，输入投资时长、风险偏好、预期目标即可生成专属方案并实现「全程自动化的账户管理」（2024年5月上线，2025年2月接入 DeepSeek-R1）。
  • 工具类模块：每日估值、资产分布分析、回测数据、指数估值（官网路径 qieman.com/idx-eval）、创建组合（自建组合，用户评价显示上限5个）等。
  • 社区/陪伴：主理人周报、直播、且慢社区（App Store 截图显示有 Community/Groups 标签页）、调仓通知与「跟车/跟调」交互（消息通知→调仓信息→开始跟调）。
  • 同路人权益体系（2025年10月上线）：以「资产规模 + 与且慢同行时长」双维度定级，含投顾服务权益（账户深度分析、家庭财务分析、海外资产规划）与实物权益。
  • 专区类：养老专区（个人养老金/1+1+1账户体系）、长赢权益专区（qieman.com/longwin/index，E大持有人专属服务，2025年10月公告上线）。

信息来源： - App Store 且慢官方页面：https://apps.apple.com/us/app/且慢/id1104871195（描述更新至2026年，含540亿规模数据） - 第三方应用情报页（含完整官方描述与截图解说）：https://mwm.ai/apps/qie-man/1104871195 - CSDN 介绍文章（2026-02-04）：https://www.csdn.net/article/2026-02-04/157723329 - 且慢官方公告（2025-10-23）：https://content.qieman.com/items/20419

1.2 与孟岩时期（2016-2019）的结构差异

孟岩自述文章显示，其在任期间且慢「没有排行榜、不做目标投、坚持只有很少的策略」；当前版本在保留严选、四笔钱骨架的基础上，增加了 AI 定制、权益体系、养老/全球专区、自建组合等更「货架化+账户化」的模块（来源：孟岩《且慢，重新说再见》，2023-04-26，https://finance.sina.cn/2023-04-26/detail-imyrtazq2724890.d.html ）。

2.2 主理人体系历史与现状

  • 孟岩：且慢创始人（产品/品牌），2015年11月加入盈米从0打造且慢，2019年11月8日被解除且慢工作、2019年12月28日对外宣布离开；后创办「有知有行」（四笔钱/温度计/长钱账户等理念延续者）。来源：孟岩《且慢，重新说再见》（2023-04-26）。
  • E大（ETF拯救世界）：长赢计划主理人，2017年4月1日上线且慢，至今仍为平台顶流（跟投超40万人）；2021年抱团行情中曾主动建议暂停新人跟投；2025年10月起在且慢社区开设长赢持有人专属权益专区。来源：孟岩文、且慢公告、雪球（https://xueqiu.com/3939439760/358069434 ，2025-10）。
  • 螺丝钉（银行螺丝钉/钉大）：其组合主阵地为蛋卷/雪球基金，非且慢主理人（且慢关联未找到公开信息）。
  • 山行：未找到公开信息（未能确认其为且慢主理人）。
  • 机构主理人（现状主力）：盈米研究院/且慢投研、交银施罗德基金（我要稳稳的幸福、哥伦布系列）、兴证全球（春华秋实）、南方基金（南方梦想佳）、华夏基金（马拉松固收增强）、建信基金等。App Store 旧版描述还提及简七、刘备教授、月风投资笔记等达人主理人（约2020年口径）。

四、规划类功能：产品形态与流程

  1. 四笔钱投资规划：以「先规划后配置」为主线——用户理清资金用途与期限 → 划分四笔钱 → 每笔钱匹配严选策略。App Store 截图显示存在「My Allocation Analysis（配置分析）」看板、「Asset Class Target Allocation（资产类别目标配置）」饼图与10年期「plan calculation（规划测算）」曲线，即规划书式的产品形态（目标配置比例 + 长期收益测算 + 持仓透视）。（来源：App Store 截图解说，mwm.ai 情报页）
  2. 定制方案：官方描述的三段式流程——投前「基于财务现状与目标定制专属投资计划书」；投中「结合行情动态调整组合配比」；投后「全程跟踪陪伴，根据资金变化灵活调整」。人工侧为「专家顾问团队定制家庭财富蓝图」，含全球风险测评、多元资产配置、现金流动态跟踪与资产全景复盘（部分能力封装在同路人高等级权益中，如家庭财务分析、海外资产规划）。AI 侧为「AI小顾」秒级生成方案并自动化账户管理。（来源：App Store 官方描述，2026）
  3. 养老规划：2022年12月上线的养老专区提供「养老计算器」（富达国际历时8个月为中国投资者定制的储蓄测算模型，示例：月入1万、55岁退休需每年储蓄2.4万）→「1+1+1」账户落地（个人养老金账户买Y份额享税优 + 补充养老投资账户 + 商业养老保险），产品覆盖目标日期/目标风险FOF、年金险、增额终身寿险。（来源：盈米官网 https://yingmi.com/archives/238 ；21财经 2022-12-19）
  4. 家庭资产配置规划：官方定位为「全球视野下的家庭财务规划」，由专家顾问定制家庭专属财富蓝图；且慢2024年起的「投顾2.0」模式即「以客户的财富目标为起点」重构服务（来源：App Store 描述；百度百科词条）。方法论沉淀于《管好四笔钱 财富滚雪球》（2024，中信出版社）。

五、推品逻辑与商业模式

  1. 买方投顾定位：收入与客户资产长期增值挂钩（「只有客户赚到钱，我们才能获得收益」）；对外强调不参与基金首发、不卖爆款、不做排行榜——2020年爆款基金潮中「顶住数百亿规模诱惑一款都没卖」（且慢公告 2025-10-23）。
  2. 四笔钱作为承接框架：规划（资金分层）→ 账户（四个心理账户）→ 推品（每个账户对应一组严选策略）。推品不以收益率排行驱动，而以「资金期限匹配」驱动：活钱→货币三佳；稳钱→我要稳稳的幸福/南方梦想佳/马拉松固收增强；长钱→长赢/春华秋实；保险→合作伙伴产品。（来源：盈米官网 2020-10 新闻稿；东方财富《智能投顾专题报告》2020-12，https://pdf.dfcfw.com/pdf/H3_AP202012041436505280_1.pdf ）
  3. 严选策略与主理人策略的关系：严选是「准入流程 + 货架呈现」——孟岩时期即建立严格的策略准入流程；2021年12月对8000+组合做严选升级后，留存策略皆纳入持牌投顾框架。主理人策略（E大长赢等外部主理 + 基金公司输出策略）是严选货架上的供给来源，且慢投研自营策略（货币三佳、八心八箭等）为补充。
  4. 投顾费率： - 2020.10–2025.10 第一批组合采用全市场独此一家的「交易费用抵扣投顾费」模式（基金申购费1折、尾佣抵扣，用户不另付投顾费）； - 2025年11月3日起改为按月收取：长赢计划（150份/S定投）<100万部分 0.5%/年、100–300万 0.45%/年、阶梯递减、每月封顶2000元（雪球 2025-10，https://xueqiu.com/3939439760/358069434 ）； - 中基协《国内外基金投顾费率机制研究》（2024-10）记载：且慢对不同投顾组合采用固定年费与按费率两种模式，按费率收取的通常在 0.2%–2.0% 区间；行业内约78%的投顾组合费率≤0.5%（https://www.amac.org.cn/hyyj/sy/202410/P020241015595094832303.pdf ）； - 变更动因：2025年行业第三次费率改革（赎回费归基金资产、销售服务费大幅下调、禁止对同一保有量重复收取客户维护费）使抵扣模式失去基础。
  5. 商业闭环：投顾费（AUM×费率）+ 基金销售收入（1折申购费、保有尾佣）+ B端能力输出（盈米「啟明」「蜂鸟」，及2025年起的且慢MCP面向机构/AI平台输出）。

对组织模式的观察：国内投顾页面大体两条路线——①「工具+货架」（雪球、天天：流量入口是行情/估值/排行工具，投顾是货架上的一类商品）；②「规划+推品」（且慢、帮你投、理财魔方：入口是规划问答/账户框架，产品作为规划结论被推出）。且慢是路线②中「账户框架化」最彻底的（四笔钱已成行业事实标准，孟岩语），2024年后又叠加 AI（AI小顾）与权益体系（同路人）来强化留存。
