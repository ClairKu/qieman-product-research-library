且慢投顾模块现况盘点报告

面向「四笔钱 / 严选策略体系升级 + 投顾一级页改版」的基线盘点：覆盖投顾页信息架构、规划/工具/专区/货架能力、上线里程碑、推品逻辑、体验问题与数据缺口。

报告日期 2026-07-23 核心目的：推品 原则：定制优先 → 标准策略 关联 改版方案

一句话结论

  • 投顾页是一级页中长期未整体升级的“货架型页面”：结构仍以「运营位 + 四笔钱货架 + 更多投资入口」为主，规划/定制/陪伴能力已在周边成熟，但未收敛成一级页主叙事。
  • 推品能力分散：四笔钱主推、严选、定制方案、养老/攒钱、工具找品并行存在；用户既要“被推荐”，也要“能查找/能调优/能 DIY”，主次不清。
  • 本次改版窗口明确：配合研究院品类矩阵与四笔钱/严选策略体系升级，应把投顾页从“策略列表页”升级为“推品中枢 + AI 可编排服务页”。

5. 推品逻辑现况 vs 目标原则

现况（实际发生）

  1. 多数用户在投顾页直接浏览四笔钱主推策略（货架选品）。
  2. 严选作为「更多选择」长列表，偏查找型用户。
  3. 定制方案存在，但入口分散在账户创建/小顾/内测链路，投顾页不主推。
  4. 规划完成后常回到标准策略，定制与标准策略的优先级未被一级页显性表达。
  5. 运营位可临时推场景，但缺少稳定的「人—场景—方案」状态机。

目标原则（本次对齐）

  1. 所有推品逻辑优先推定制方案，再推标准策略。
  2. 标准策略按品类矩阵分层：四笔钱主推层 / 严选层 / 长尾层。
  3. 活钱、稳钱可继续优先标准策略（已能较好满足）；长钱/复杂目标优先定制。
  4. 支持四类用户意图并行，但主次分明：被推荐 / 按持仓调优 / 按目标选品 / DIY 找品。
  5. 合规与适当性：展示与推荐需可解释、可留痕；避免纯货架式“随便挑”。
用户意图现有承接主次建议一级页处理
主动被推荐 运营位、四笔钱货架、小顾 主 首屏「为我推荐」：定制优先，否则主推策略
按目标选品 四笔钱 Tab、攒钱、养老、账户目标 主 目标导航（四笔钱/场景）→ 方案
按持仓调优 账户诊断、资产分析、小顾诊断 次主 有持仓用户展示「优化建议摘要」跳转
查找 / DIY 严选列表、估值、自建、搜索 辅 工具与严选下沉，不占首屏

6. 产品体验问题（证据化）

结构与定位

  • 与首页推品/四笔钱内容重叠（客服周报多次反馈）。
  • 规划入口历史像 Banner，服务感弱（2023 APP 改版思路已指出）。
  • 工具入口藏得深（估值等），专业用户找得到，大众用户找不到。
  • 定制方案未成为一级页主 CTA。

推品与认知

  • 用户仍在「选策略」，而非「确认方案」。
  • 四笔钱、账户、组合、方案术语成本高。
  • 严选与主推边界对用户不清晰（只是更多列表）。
  • 风险—收益关系主要靠卡片数字，缺少空间化理解。
